No project should be coded without testing. Manual testing and code reviews should be completed along with automated testing. No testing method is perfect that's why multiple types of testing should be done. And when changes are made to previously tested code regression testing needs to be performed. You can verify the security of programs by creating JUnit tests against common exploits, like entering invalid or sensitive information. 

It can be difficult to interpret user requirements. In the case of designing software for others the focus should be a creating a product that functions well for them. Having something easy to use is my priority. Don't be afraid to ask questions about what the user wants. Or better yet have them test the program once a basic prototype has been created.
